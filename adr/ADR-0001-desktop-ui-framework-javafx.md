# ADR-001: Выбор графического фреймворка JavaFX для настольного клиента

## Контекст и постановка задачи

Настольный клиент системы «Трекер финансов» должен работать на операционных системах Windows 10/11, macOS 12+ и Ubuntu 22.04+ (REQ-PORT-001), обеспечивать построение аналитических диаграмм расходов и динамики баланса (REQ-FUNC-015..017), управление клавиатурой без мыши (REQ-INT-004), работу с экранами от 1024×720 (REQ-INT-005) и импорт/экспорт файлов CSV (REQ-FUNC-020..021). Необходимо выбрать технологический стек разработки графического интерфейса настольного приложения в экосистеме Java 17+.

## Драйверы решения

- Поддержка современных стандартов UI, стилизации через CSS и декларативной разметки.
- Наличие встроенных компонентов визуализации данных (PieChart, BarChart, LineChart).
- Кроссплатформенность без перекомпиляции под каждую настольную ОС.
- Изоляция UI-слоя от сетевых вызовов и бизнес-логики.
- Нулевая стоимость лицензий и открытый исходный код (REQ-COMP-001).

## Рассмотренные варианты

1. JavaFX 21+ с FXML и CSS-стилизацией.
2. Библиотека Swing / FlatLaf с ручной отрисовкой графиков на Java2D.
3. Web-оболочка на Electron / Chromium с оберткой над локальным веб-интерфейсом.

## Итог решения

Выбран вариант 1. Графический интерфейс настольного клиента реализуется на JavaFX 21+. Разметка экранов выносится в FXML-файлы, стили оформляются в CSS, а для построения круговых и столбчатых отчетов используются штатные компоненты пакета `javafx.scene.chart`. Сетевые вызовы к REST API выполняются асинхронно в фоновых потоках `javafx.concurrent.Task` с обновлением интерфейса в потоке JavaFX Application Thread.

### Последствия

- Для запуска приложения требуется наличие модулей JavaFX или упаковка дистрибутива через утилиту `jpackage` с встроенным runtime.
- Стилизация через CSS обеспечивает единообразный внешний вид и легкую поддержку темной темы оформления.
- Встроенные диаграммы закрывают требования REQ-FUNC-015 и REQ-FUNC-016 без подключения сторонних тяжеловесных графических библиотек.

### Подтверждение

Тесты проверяют запуск главного окна на эталонных разрешениях от 1024×720, корректную отрисовку диаграмм за 12 месяцев при тестовом наборе в 10 000 операций (REQ-PERF-003) и отзывчивость интерфейса при сетевых операциях.

## Плюсы и минусы вариантов

| Вариант | Плюсы | Минусы |
|---|---|---|
| JavaFX 21+ | Встроенные графики, FXML, стилизация CSS, нативная скорость | Требует модулей JavaFX при сборке |
| Swing + FlatLaf | Входит в стандартную поставку JDK | Устаревший API, нет встроенных современных графиков |
| Electron | Гибкая веб-верстка | Большой размер дистрибутива (>150 МБ), высокое потребление ОЗУ (>300 МБ) |
