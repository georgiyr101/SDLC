# Глоссарий проекта «Трекер финансов»

**Версия:** 1.0  
**Дата:** 16.11.2026  
**Основа:** Спецификация требований к ПО (SRS v0.2), Описание дизайна (SDD v1.0)

Настоящий глоссарий фиксирует единую терминологию предметной области личного финансового учёта и технической архитектуры кроссплатформенной системы «Трекер финансов» (Desktop JavaFX, Android Jetpack Compose, iOS SwiftUI, Spring Boot, PostgreSQL).

| № | Термин | Английский эквивалент / Синоним | Определение в контексте системы | Связанные требования SRS |
|:---:|---|---|---|---|
| 1 | **Пользователь (Владелец бюджета)** | User / Budget Owner | Физическое лицо, зарегистрированное в системе и ведущее учёт личных счетов, доходов, расходов и месячных лимитов через десктопный или мобильный клиент. | `REQ-FUNC-024`, `REQ-FUNC-031` |
| 2 | **Счёт** | Account | Именованная финансовая сущность пользователя определённого типа (`Наличные`, `Банковская карта`, `Вклад`, `Накопительный счёт`) в одной фиксированной валюте с начальным и текущим балансом. | `REQ-FUNC-001`, `REQ-FUNC-002` |
| 3 | **Текущий баланс** | Current Balance | Актуальный остаток средств на счёте, вычисляемый сервером с точностью до копейки в типе `BigDecimal` по формуле: `Начальный баланс + Доходы − Расходы + Входящие переводы − Исходящие переводы`. | `REQ-FUNC-002`, `REQ-REL-003` |
| 4 | **Транзакция (Операция)** | Transaction | Зафиксированное финансовое событие одного из трёх типов: `INCOME` (доход), `EXPENSE` (расход) или `TRANSFER` (межсчётный перевод), с суммой, датой, счётом, категорией и описанием. | `REQ-FUNC-004`..`REQ-FUNC-007` |
| 5 | **Межсчётный перевод** | Inter-Account Transfer | Операция перемещения денежных средств между двумя активными счетами одного пользователя в одной валюте; изменяет остатки обоих счетов атомарно, не влияя на доходы и расходы бюджета. | `REQ-FUNC-007`, `REQ-REL-001` |
| 6 | **Категория** | Category | Классификатор операций дохода или расхода (`Продукты`, `Транспорт`, `Зарплата` и др.). Может быть системной (из базового справочника из 11 категорий) или пользовательской. | `REQ-FUNC-009`, `REQ-FUNC-010` |
| 7 | **Мягкая архивация** | Soft Archiving | Механизм скрытия счёта или категории из форм создания новых операций с сохранением всех исторических транзакций для целостности отчётов вместо физического удаления из БД. | `REQ-FUNC-003`, `REQ-FUNC-010` |
| 8 | **Автокатегоризация** | Rule-Based Auto-Categorization | Детерминированный алгоритм автоматического подбора категории по точному или подстрочному совпадению ключевых слов в описании транзакции (без применения ИИ/МО). | `REQ-FUNC-011` |
| 9 | **Лимит расходов месяца (%)** | Monthly Budget Limit (%) | Доля суммарного дохода текущего календарного месяца (от 1% до 100%), которую пользователь планирует не превышать в качестве расходов. Задаётся при внесении дохода. | `REQ-FUNC-012` |
| 10 | **Абсолютная сумма лимита** | Calculated Budget Limit | Рассчитываемый сервером денежный потолок трат на месяц: `Сумма доходов месяца × (Процент лимита / 100)` с округлением `HALF_UP` до 2 знаков. | `REQ-FUNC-014`, `REQ-REL-003` |
| 11 | **Остаток лимита** | Remaining Budget | Разница между абсолютной суммой лимита и суммой всех расходов текущего месяца (без учёта переводов). При превышении бюджета принимает отрицательное значение. | `REQ-FUNC-013` |
| 12 | **Светофорный статус бюджета** | Traffic-Light Budget Status | Визуальный и текстовый индикатор освоения месячного лимита: `NORMAL` (< 80%, зелёный), `WARNING` (80%–100%, жёлтый), `EXCEEDED` (> 100%, красный). | `REQ-FUNC-013`, `REQ-INT-004` |
| 13 | **Push-уведомление о лимите** | Budget Threshold Push Notification | Локальное или системное оповещение на смартфонах Android и iOS, инициируемое службой `BudgetNotificationService` при пересечении порогов 80% и 100% месячного лимита. | `REQ-FUNC-014` |
| 14 | **Регулярный платёж** | Recurring Payment | Шаблон периодически повторяющейся финансовой операции (ежемесячной или еженедельной), автоматически порождающий транзакции по расписанию без участия пользователя. | `REQ-FUNC-008` |
| 15 | **Идемпотентность планировщика** | Scheduler Idempotency | Свойство службы `RecurringPaymentService` проверять дату последнего исполнения (`last_executed_date`), исключая двойное списание при повторном запуске или сбое сервера. | `REQ-FUNC-008`, `REQ-REL-001` |
| 16 | **Биометрическая разблокировка** | Biometric Unlock / Quick Auth | Быстрый локальный доступ к авторизованной мобильной сессии с использованием системных сенсоров (FaceID, TouchID, BiometricPrompt) или 4-значного PIN-кода вместо повторного ввода пароля. | `REQ-SEC-002` |
| 17 | **JWT (Access / Refresh Token)** | JSON Web Token | Криптографически подписанный токен авторизации (Bearer): короткоживущий Access Token (до 60 мин) для запросов к API и долгоживущий Refresh Token (до 30 дней) для продления сессии. | `REQ-FUNC-025`, `REQ-INT-008` |
| 18 | **Защищённое хранилище токенов** | Secure Token Storage | Изолированное аппаратно-программное хранилище ОС на мобильном устройстве (Android KeyStore, Apple iOS Keychain) для сохранения Refresh-токена и хеша PIN-кода. | `REQ-FUNC-025`, `REQ-SEC-004` |
| 19 | **Изоляция арендаторов** | Multi-Tenancy Isolation | Серверная политика безопасности, при которой каждая SQL-операция строго фильтруется по `user_id` из проверенного JWT-токена, исключая доступ к чужим финансовым записям. | `REQ-SEC-007` |
| 20 | **BigDecimal / NUMERIC(19,2)** | Exact Decimal Representation | Представление денежных сумм в Java и PostgreSQL с фиксированной десятичной точкой, исключающее двоичные погрешности округления типов `float` и `double`. | `CON-04`, `REQ-REL-003` |
| 21 | **Эталонный CSV-формат** | Standard CSV Export Format | Файл выписки операций в кодировке UTF-8 с разделителем `,` или `;` и заголовком `Date,Type,Amount,Currency,Account,Category,Description`, совместимый с Excel и LibreOffice. | `REQ-INT-007`, `REQ-FUNC-020` |
| 22 | **Синхронизация клиентов** | Cross-Platform Data Sync | Актуализация балансов, операций и статусов бюджета на Desktop, Android и iOS через единый REST API `/api/v1/...` со временем отображения изменений не более 3 секунд. | `REQ-FUNC-026`, `REQ-INT-008` |
