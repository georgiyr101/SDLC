# Проект по дисциплине «Жизненный цикл разработки ПО»

* **ФИО:** Романчук Георгий Александрович
* **Группа:** 450501

## Описание проекта
Утилита на Java («Калькулятор Тортиков») с архитектурой MVC и активной моделью, которая рассчитывает финансовые затраты на курение, объём смол и никотина, а также их эквивалент в количестве тортиков и апельсинов с поддержкой восстановления данных.
